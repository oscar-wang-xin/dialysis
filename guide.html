01

装到手机桌面

  1. 把整个工具包文件夹（6 个 HTML）传到手机（微信发给自己、或用数据线拷进去都行）。
  2. 用手机自带的浏览器打开其中的 html 文件。不要在微信里直接点开，微信内置浏览器存不住数据。
  3. 安卓浏览器：右上角菜单 → 添加到主屏幕。
    苹果 Safari：底部分享按钮 → 添加到主屏幕。
  4. 桌面会出现一个图标，以后点它就能开，断网也能看。
为什么要装到桌面：老人不用记路径，出事时一眼能找到；也避免每次都在聊天记录里翻文件。
02

头三天要做完的事

  1. 在综合卡「应急」页填好透析中心、主治医生、家属三个号码，点保存。号码会变成可点的链接。
  2. 在「陪护」页把正在吃的药逐条加进去：药名、时间、几片、要不要随餐。特别是磷结合剂和降压药。
  3. 选好每周哪几天透析、上午还是下午。
  4. 在「记录」页存第一条，把今天的体重和血压记下来，形成习惯。
  5. 点一次导出备份文件，存到微信收藏或网盘，换手机时用得上。
  6. 打开一次「照护知识」，知道 60 条宣教链接在哪儿。
03

每天怎么用

  • 早上：上完厕所、空腹称重 → 打开「记录」填体重、血压 → 保存，两分钟。
  • 做饭前：翻「饮食」，确认今天的菜要不要焯水、汤算不算水。
  • 出门透析前：开「陪护」，把打包清单一条条勾上，回来点"全部取消"。
  • 吃药时：对照「陪护」里的药单，别凭记忆。
  • 复诊前：「记录」里点"导出给医生"，把文字发过去或打印出来。
  • 拿不准的时候：翻「照护知识」的常识卡和排查清单；它只提醒该记什么、该问谁，不替你下结论。
04

出事时怎么用

  • 直接开应急速查卡，从上往下找到对应的那条，照着做。
  • 能打电话就先打：透析中心不通就打 120，别在页面上犹豫。
  • 出血的，一只手按住，另一只手打电话。
  • 人叫不醒的，不要喂任何东西，侧躺等救护车。
页面只是提醒：它不会替你判断病情。真正决定怎么处理的是透析室护士和肾内科医生。
05

数据会不会丢

所有内容存在这台设备的浏览器里，不上传任何服务器。清理浏览器缓存、换手机、卸载浏览器，数据就没了。所以：

  • 每周点一次「导出备份文件」，存到微信收藏。
  • 换手机时，在新手机上打开同一个页面 → 「恢复」→ 选那个 json 文件。
  • 复诊前导出文本，等于给医生留了一份纸质之外的副本。
保存了，第二天打开却不见了

多半是微信里直接打开的，或者浏览器关了"本地存储"。请改用手机自带浏览器（Safari / Chrome / 华为浏览器），并添加到主屏幕后再用。

点了号码没反应

号码没填，或者是空链接。回到综合卡「应急」页的"填写 / 修改号码"，填完点保存。填好后号码会变成青绿色，可以直接点。

夜里看太亮

右上角的月亮按钮切换夜间模式，会记住选择。应急速查卡本身是深色的，夜里不刺眼。

能不能打印出来贴墙上

可以。用电脑浏览器打开应急卡或记录页，按 Ctrl+P 打印。记录页已经做了打印样式，按钮和工具栏不会印出来。
